# Syngine Documentation
# Concept: Rendering - Shaders & Uniforms
[<-- Back](../index.md)

Syngine's Standard Render Pipeline (SRP) is built to be primarily data-driven. The system uses a strict separation of powers to make it easy to extend data to both new engine and user-generated content.


## Shaders
Shaders in Syngine are stateless definitions of GPU programs. They own their uniform handle(s).

Shaders rely on an XML metadata file in the shader bundle to define what uniforms they expect, their data type, their frequency, and how they map to memory. This XML file is generated by the build system using `syntools` before shader compilation.

Shaders may define uniforms, material parameters, and texture samplers using comments in the shader source.

Uniform types:
- SAMPLER
- VEC4
- MAT3
- MAT4

Uniform frequencies:
- FRAME - Global state variables (Time, wind, etc). Updated once per frame.
- VIEW - Camera state (View projection). Updated once per active view.
- DRAW - Object state (Transforms, material parameters, samplers). Updated per object.

## Uniforms
Uniforms are data passed to the GPU from the CPU. Here, we strictly define a Uniform as a constant, rather than including texture samplers and material parameters (See [Materials](./materials.md)).

### The Uniform Registry
The registry bridges together gameplay logic and the renderer without physically coupling them in code. It uses type erased function pointers to supply data to the GPU on demand. These function pointers are provided the `RenderPacket` as a `context` argument, which is only provided during DRAW uniforms. The context should be cast back to its type using `const T& data = UniformRegistry::GetContext<const T*>(context)`

### Uniform Data Providers
Uniform Data Providers are the earlier mentioned function pointers used to provide GPU bound data. Shaders ask for one of these providers when defining a uniform. These functions should be as simple and flat as possible as they are called during the render process. An example of a UDP could be:
```cpp
UniformRegistry::RegisterProvider(
    "Camera.ViewProjection",
    UniformDataProvider{
        .type = UniformType::MAT4,
        .frequency = UniformFrequency::VIEW,
        .num = 1,
        .getter = [](const void* rawPacket) -> const void* {
            return Renderer::GetActiveCamera()->GetViewProjMatrix().data();
        }
    }
);
```
Or
```cpp
UniformRegistry::RegisterProvider(
    "Billboard.Position",
    UniformDataProvider{
        .type = UniformType::VEC4,
        .frequency = UniformFrequency::DRAW,
        .num = 1,
        .getter = [](const void* rawPacket) -> const void* {
            const RenderPacket& packet = UniformRegistry::GetContext<const RenderPacket>(rawPacket);
            TransformComponent transform = packet.go->GetComponent<TransformComponent>();

            thread_local Math::Vec4 data;
            data = { transform->GetWorldPosition(), 0.0f };

            return data.data();
        }
    }
);
```
